# v0.2.0 — public preview preparation

This release turns the device-tested 14.3.1 patch into a source-first contribution baseline. It does not claim support for new vendor versions or additional physical devices.

- English/Chinese homepage with an original HUD illustration, clear compatibility, quick start and troubleshooting.
- Read-only `doctor` and `inspect`, machine-readable output and actionable failures.
- Separate player, HLS and worker adapter modules; explicit platform/Sony profiles; one version source for CLI, HUD and archive.
- Linux/macOS source CI; Android HUD build verification; allowlisted source archive with per-file and archive SHA-256 checks; manual draft-only release workflow.
- Contribution/security policies, community conduct and structured issue/PR templates.

Eight combinations of prefetch, reclaim and platform/128 MiB video budget produce exactly the same three patched JavaScript assets as the pre-refactor baseline. No new playback behavior is intentionally introduced.

See [validation](../validation.md) for evidence and [release checklist](../releasing.md) for remaining maintainer actions. Remote CI and public publication are not completed by local release preparation. Vendor or patched Apple APKs, personal configuration, logs and keys are excluded from source distribution.

- Fixed pending UP requests leaking into another playback page: ordered UI snapshots, lifecycle-bound requests, and cancellation on exit, hide, manual toggle or stale heartbeat. Added regression coverage for delayed keys, expiry and same-page controls.
