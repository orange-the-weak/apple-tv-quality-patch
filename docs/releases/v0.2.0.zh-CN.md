# v0.2.0 — 开源预览版发布准备

本次把已经实机测试的 14.3.1 补丁整理为可贡献、可复现的源码项目，不新增原厂版本或其他设备的兼容承诺。

- 中英文首页、原创 HUD 示意图、兼容性、快速开始与排错指南。
- 只读 `doctor` 和 `inspect`，支持 JSON 输出及明确修复建议。
- 播放界面、HLS、worker 模块分离；通用与 Sony 配置显式选择；CLI、HUD、源码包共用版本号。
- Linux/macOS 源码 CI、Android HUD 构建验证、白名单源码包与双层哈希核验、手动草稿 Release 工作流。
- 贡献、安全、社区行为规范及结构化 Issue/PR 模板。

预取、回收与通用/128 MiB 组合的 8 种配置，生成的三个播放器脚本均与重构前逐字节一致。本次没有主动改变播放行为。

验证结果见[验证记录](../validation.zh-CN.md)，维护者剩余步骤见[发布流程](../releasing.zh-CN.md)。源码仓库已公开，[首次远端 CI 已通过](https://github.com/orange-the-weak/apple-tv-quality-patch/actions/runs/44232924347)；尚未发布带版本标签的 GitHub Release。源码发布不含原厂或修改版 Apple APK、个人配置、日志或密钥。

- 修复待处理上键请求串入下一播放页：UI 状态按顺序处理，请求绑定播放会话，退出、隐藏、手动切换或心跳失效时取消；补充延迟按键、过期和同页控制栏回归检查。
